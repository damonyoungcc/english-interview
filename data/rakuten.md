## Business Overview
The Technology Platforms Division (TPD) is responsible for building and operating the infrastructure and ecosystem platforms which power the Rakuten Group. Our mission is to provide our Rakuten Cloud and Ecosystem Platforms which will deliver Core Value to accelerate the growth of Rakuten Group services.

技术平台部门（TPD）负责构建和运营支撑乐天集团的基础设施与生态系统平台。我们的使命是提供乐天云与生态系统平台，创造核心价值，助力乐天集团各项服务的加速发展。

### Department Overview
The Incentive Platform Department (INPD) provides incentive[激励] and payment solutions that empower Rakuten's businesses around the world. The platforms are continually adding capabilities and scale to accelerate the Rakuten ecosystem synergies[协同].

Incentive Platform Department (INPD) 提供激励和支付解决方案，帮助乐天在全球范围内的业务发展。这些平台不断增强功能和扩大规模，以加速乐天生态系统内部的协同效应。

### Job Description
As a Front-End Developer, you will be responsible for developing and maintaining web applications using modern technologies and frameworks. You will work closely with our design, backend, and product teams to create seamless and performant user interfaces.
Your role will involve translating design wireframes into high-quality code, optimizing applications for maximum speed, and ensuring the technical feasibility of UI/UX designs.
Develop new user-facing features.Build reusable components and front-end libraries for future use.

作为一名前端开发工程师，你将负责使用现代技术和框架开发和维护网页应用程序。
你将与设计团队、后端团队和产品团队密切合作，打造流畅且高性能的用户界面。

你的工作内容包括：
将设计线框图转化为高质量的代码、优化应用程序以实现最快的加载速度、并确保 UI/UX 设计在技术上的可行性。开发面向用户的新功能。构建可复用的组件和前端库，便于未来使用。

### Key Responsibilities:
- Optimize components for maximum performance across a vast array of webcapable devices and browsers.
- Implement state management solutions such as Redux or Zustand.
- Write unit tests using Jest and Vite and perform E2E testing with Cypress or Playwright.
- Stay up to date with the latest ECMAScript methods and front-end development best practices.
- Participate in the CI/CD pipeline setup and maintenance using tools like Jenkins and AWS CodeBuild.
- Assist in migrating existing front-end applications to the React framework.

- 优化组件，使其在各种支持网页的设备和浏览器上都能达到最佳性能。
- 实现状态管理方案，例如 Redux 或 Zustand。
- 使用 Jest 和 Vite 编写单元测试，并使用 Cypress 或 Playwright 进行端到端测试（E2E测试）。
- 持续学习最新的 ECMAScript 方法和前端开发最佳实践。
- 参与 CI/CD 流水线的搭建与维护，使用工具如 Jenkins 和 AWS CodeBuild。
- 协助将现有的前端应用程序迁移到 React 框架下。

### Requirements:
- Proven experience as a Front End Developer or similar role.
- Strong proficiency in HTML, CSS, and JavaScript.
- Hands-on experience with React.js and TypeScript.
- Familiarity with state management libraries such as Redux or Zustand
- Experience with unit testing frameworks like Jest and Vite.
- Proficiency in E2E testing tools such as Cypress or Playwright.
- In-depth understanding of ECMAScript standards and modern JavaScript features.
- Knowledge of front-end security practices, including CSP, XSS, CSRF, and JWT.
- Experience with CI/CD pipelines and tools like Jenkins and AWS CodeBuild.
- Ability to migrate front-end applications to React.
- Experience with Docker and containerization.
- Familiarity with responsive design frameworks like Bootstrap or MUI.

- 具备前端开发工程师或类似职位的实际工作经验。
- 精通 HTML、CSS 和 JavaScript。
- 拥有 React.js 和 TypeScript 的实际开发经验。
- 熟悉状态管理库，例如 Redux 或 Zustand
- 具备使用单元测试框架（如 Jest 和 Vite）的经验。
- 熟练使用端到端（E2E）测试工具，例如 Cypress 或 Playwright。
- 深入理解 ECMAScript 标准和现代 JavaScript 特性。
- 了解前端安全实践，包括 CSP（内容安全策略）、XSS（跨站脚本攻击）、CSRF（跨站请求伪造）和 JWT（JSON Web Token）。
- 具有使用 CI/CD 流水线及工具（如 Jenkins 和 AWS CodeBuild）的经验。

- 有 Docker 及容器化开发经验。
- 熟悉响应式设计框架，例如 Bootstrap 或 MUI（Material UI）。
